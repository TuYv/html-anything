# Bundled audio attribution

The BGM tracks (`bgm/`) and sound effects (`sfx/`) in this directory are vendored
from **[alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design)**,
distributed under the MIT License. The upstream license text is preserved in
`LICENSE-huashu.txt` as required by MIT.

These assets are exposed to the local agent (for video skills only) via the
`HTML_ANYTHING_AUDIO_DIR` environment variable — see `lib/audio/assets.ts`.
