# 研发节奏对比图

请生成一页 1920×1080 HTML, 对比传统研发节奏和 Agents Team 模式研发节奏。

口径: 以开发量为一周时长的需求为例。

传统模式:
- 拆分: 0.5PD
- 前端开发: 5PD
- 后端开发: 5PD
- 单测: 算在编码内
- 联调: 1.5PD
- 自测 / 修 bug: 2PD
- CR: 0.5PD
- 测试: 2.5PD
- 上线: 不计入
- 合计: 17PD
- 研发周期: 10d

Agents Team:
- 方案确定: 1PD
- 前后端 Agent 合计: 1PD
- 人工 CR: 2PD
- 测试: 2.5PD
- 上线: 不计入
- 合计: 6.5PD
- 研发周期: 6.5d

呈现要求:
- 只要一页, 整体 1920×1080。
- 最好用一个图表展现研发节奏变化和效率提升。
- 两条流程必须按实际 PD 比例绘制块宽。
- 测试环节两边都必须保留。
- 在传统流程条下方加一个大括号, 标识后端 / 前端 Agent 把「拆分、编码、单测、联调、自测 / 修 bug」内化压缩为 1PD。
- 右侧展示单需求人日 17PD → 6.5PD、研发周期 10d → 6.5d。
- Token 成本: 2kw Token, 约 ¥2k, 不区分 input / output。
